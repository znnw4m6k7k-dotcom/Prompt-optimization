# ADR 0001：模型无关编排

- 状态：已接受
- 日期：2026-11-25

## 背景

不同用户的模型可用性、成本、延迟和数据合规要求差异很大。把产品绑定到单一厂商，会失去离线、内网和自托管场景。

## 决策

定义稳定的 Provider 契约，让 CLI、HTTP、MCP 和 Schema 不依赖具体模型。首批支持 OpenAI-compatible、Anthropic、Ollama；没有 Provider 时使用确定性编译器。

## 后果

- 同一套接口适配多个模型；
- 增加适配器和 Provider 特定错误处理；
- 质量随模型变化，必须分 Provider 评测；
- 不被单一厂商锁定。

## 备选方案

- 单一厂商 SDK：简单，但违背本地/私有部署目标；
- 自研基础模型：成本高，v0.1.0 没有证据表明必要。
