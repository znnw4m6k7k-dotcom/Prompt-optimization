# ADR 0003：离线编译器作为基线

- 状态：已接受
- 日期：2026-11-25

## 背景

提示词增强应能在没有 API Key、网络或 GPU 的情况下工作，同时需要一个确定性基线用于测试和回归。

## 决策

实现基于目标 profile 的规则编译器。没有 Provider 时默认使用它，也可作为失败降级路径和评测基线。

## 后果

- 零成本、零延迟、离线可用；
- 输出稳定，适合测试；
- 语义理解有限；
- LLM 路径必须证明相对基线有可测量提升。

## 备选方案

- 强制依赖 LLM：语义更强，但无离线模式、门槛高；
- 只用小模型：依赖硬件，难以确定性测试。
