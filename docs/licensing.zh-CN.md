# 开源许可证选择

## 选择：Apache License 2.0

本项目采用 Apache-2.0。

## 理由

| 维度 | Apache-2.0 | MIT |
| --- | --- | --- |
| 商业使用 | 允许 | 允许 |
| 修改与分发 | 允许 | 允许 |
| 专利授权 | 明确授予 | 未明确 |
| 商标授权 | 不授予 | 不涉及 |
| 专利报复条款 | 有 | 无 |
| 合规成本 | 中等 | 低 |
| 企业采用友好度 | 高 | 高 |

Prompt Refinery 是基础设施型工具，可能被企业集成到桌面客户端、内部平台和商业产品中。Apache-2.0 的明确专利授权和专利报复条款比 MIT 更适合这种场景，同时仍保持宽松许可。

## 不选择 copyleft 的原因

GPL/AGPL 会限制闭源桌面客户端和商业分发，降低 Agent 生态的集成意愿。项目目标是“让各类桌面 Agent 都能方便调用”，因此不使用 copyleft。

## 贡献者许可

除非另有明确说明，提交到本仓库的贡献按 Apache-2.0 授权。项目不要求 CLA；贡献者需确保有权提交其代码。

## 第三方材料

- 依赖必须与 Apache-2.0 兼容；
- 引入新依赖时需在 PR 中说明许可证；
- 不得提交来源不明或授权不清的代码、提示词或数据；
- 文档引用第三方内容时注明来源。

## 商标

Apache-2.0 不授予项目名称、Logo 或商标使用权。详见 [NOTICE](../NOTICE)。
